> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 평상시에는 문서만 보이고, 한 번 탭하면 겹쳐 뜨는 오버레이·패널·핸들·단축키·확대로 긴 문서와 여러 파일 사이를 쉽게 오가는 읽기 UI를 확정 디자인(§13)으로 만든다.

## Global Constraints

- P1의 Global Constraints 전부.
- 레이아웃 경계: 뷰포트 폭 **768px 이상 = PC 레이아웃**, 미만 = 모바일 레이아웃(인덱스 스펙 이슈 6). `src/ui/layout.svelte.ts`의 `layout.desktop`(rune 상태, `matchMedia('(min-width: 768px)')` 구독) 하나만 기준으로 쓴다.
- 모바일 레이아웃: 리더 UI는 전부 오버레이(iframe 크기·위치를 바꾸지 않는다). PC 레이아웃: 상단 바 1개가 항상 보이고 우측 패널은 도킹된다(인덱스 스펙 이슈 13).
- 오버레이·시트 애니메이션은 `transform`/`opacity`만. 바 배경은 `var(--bar)` + `backdrop-filter: blur(22px) saturate(1.6)` + 1px `var(--hairline)` 경계. 바는 플로팅 캡슐이 아니라 화면 가장자리에 붙는다.
- 오버레이 상단 바는 화면 맨 위부터(`padding-top: var(--sat)`), 하단 바는 맨 아래까지(`padding-bottom: var(--sab)`).
- 아이콘은 인라인 스트로크 SVG(1.8px). **이모지 금지.** 터치 대상 ≥ 44px. 글꼴 `Pretendard Variable`(번들) → `system-ui`.
- 앱 테마는 앱 크롬에만 적용한다. 문서(iframe 안)에는 어떤 스타일도 넣지 않는다(확대의 `zoom` 제외).
- 브라우저 확대 `Ctrl/⌘ +/-`와 브라우저 찾기 `Ctrl/⌘+F`는 가로채지 않는다.
- 모바일 전용 E2E는 `*.mobile.spec.ts`, PC 전용은 `*.desktop.spec.ts`로 이름 짓는다.

## Review Focus

1. **오버레이가 열린 채 문서 안 링크로 페이지가 바뀜** — 쪽 정보·진행 바·핸들이 새 페이지 값으로 바뀌고 이전 페이지 값이 남지 않는다. (Task 3)

// tests/unit/tokens.test.ts — §13.1 WCAG AA
import { readFileSync } from 'node:fs';
import { expect, test } from 'vitest';
const css = readFileSync('src/ui/theme/tokens.css', 'utf8');
const block = (dark: boolean) => (dark ? css.split(':root[data-theme="dark"]')[1] : css.split(':root[data-theme="dark"]')[0]);
const tok = (name: string, dark: boolean) => new RegExp(`--${name}:\\s*([^;]+);`).exec(block(dark))![1].trim();
const rgba = (v: string): [number, number, number, number] => v.startsWith('#')
  ? [parseInt(v.slice(1, 3), 16), parseInt(v.slice(3, 5), 16), parseInt(v.slice(5, 7), 16), 1]
  : (v.match(/[\d.]+/g)!.map(Number) as any).concat(1).slice(0, 4);
const over = (fg: number[], bg: number[]) => fg.slice(0, 3).map((c, i) => c * fg[3] + bg[i] * (1 - fg[3]));
const lum = (c: number[]) => { const [r, g, b] = c.map((v) => { v /= 255; return v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4; }); return 0.2126 * r + 0.7152 * g + 0.0722 * b; };
const ratio = (a: number[], b: number[]) => { const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p); return (x + 0.05) / (y + 0.05); };

test.each([false, true])('토큰 값과 대비 (dark=%s)', (dark) => {
  const surface = rgba(tok('surface', dark));
  for (const [fg, bg] of [['text', 'bg-app'], ['text-2', 'surface'], ['text-3', 'surface'], ['text-3', 'bg-app'], ['accent', 'surface'], ['ok', 'surface']])
    expect(ratio(rgba(tok(fg, dark)), rgba(tok(bg, dark))), `${fg} on ${bg}`).toBeGreaterThanOrEqual(4.5);
  for (const k of ['warn', 'info']) expect(ratio(rgba(tok(`${k}-fg`, dark)), over(rgba(tok(`${k}-bg`, dark)), surface)), k).toBeGreaterThanOrEqual(4.5);
});
test('스펙 표의 값 그대로', () => {
  expect([tok('bg-app', false), tok('bg-reader', false), tok('accent', false), tok('bar', false)]).toEqual(['#EEF0F4', '#FFFFFF', '#2F6FEB', 'rgba(250,251,253,0.86)']);
  expect([tok('bg-app', true), tok('bg-reader', true), tok('accent', true), tok('surface', true)]).toEqual(['#101216', '#000000', '#6EA0FF', '#1A1D23']);
});

### Task 2: 탭 판별(agent) + 오버레이 토글(셸)

**Files:** Create: `src/agent/tap.ts`, `src/ui/reader/Overlay.svelte` / Modify: `src/agent/main.ts`, `src/ui/reader/Reader.svelte`, `tests/e2e/helpers.ts` / Test: `tests/e2e/overlay.mobile.spec.ts`

**Interfaces:**
- Consumes: `SessionHooks.onTap`, `protocol`의 `tap`
- Produces:
  - agent `installTap(send: (m: AgentMsg) => void): void`
  - `Overlay.svelte` props: `{ open: boolean; title: string; children 슬롯(top-actions, bottom) }` — `overlay-top`(안에 `reader-back`, 문서명, `page-info` 자리, 우측 액션 영역), `overlay-bottom`. `open=false`일 때 `transform: translateY(∓100%)` + `opacity: 0` + `pointer-events: none` + `inert`.
  - `Reader.svelte` 상태: `overlayOpen`(→ `data-overlay`), `OVERLAY_HIDE_MS = 3000`, `holdOverlay(reason: string): () => void`(드래그·패널 사용 중 자동 숨김을 막는 잠금, 해제 함수 반환), `pokeOverlay()`(조작 시 타이머 재시작)
  - 헬퍼: `openOverlay(page)`(모바일: `ribbon-tab`이 있으면 그것을, 없으면 문서의 빈 곳을 탭 → `data-overlay="open"` 대기), `backToLibrary`는 "`reader-back`이 안 보이면 `openOverlay` 먼저"로 갱신. P1의 임시 좌상단 `reader-back`은 제거하고 `overlay-top` 안으로 옮긴다.

탭 판정(§6.3 — 모두 만족해야 `tap`):
- `pointerdown`~`pointerup` 이동 ≤ 10px, 시간 ≤ 300ms, 주 버튼(또는 터치) 1개
- `getSelection().toString() === ''`
- 대상과 조상에 `a, button, input, select, textarea, label, summary, video, audio, iframe, [role=button], [role=link], [role=tab], [role=menuitem], [role=checkbox], [contenteditable], [onclick], [tabindex]` 없음(`closest`)
- 대상의 `getComputedStyle(target).cursor !== 'pointer'`
- 그 포인터 동작으로 생긴 `click`이 **window의 버블 단계**까지 왔고 `defaultPrevented === false`. (문서가 `stopPropagation`하면 click이 오지 않으므로 탭 아님 — 안전한 쪽)

구현 방식: `pointerdown`/`pointerup`은 capture 단계에서 좌표·시간만 기록하고, 판정과 전송은 window 버블 단계의 `click` 리스너에서 한다. 리스너는 모두 passive, `preventDefault` 호출 없음.

셸: 모바일 레이아웃에서 `onTap` → `overlayOpen` 토글. 열려 있을 때 3초 무조작이면 닫는다. PC 레이아웃에서는 `onTap`을 무시하고, `overlay-top`을 항상 열린 상태로 고정하며 `overlay-bottom`은 렌더링하지 않는다(그래야 PC 프로젝트의 기존 스펙이 `reader-back`에 닿는다. PC 상단 바의 세부 배치와 iframe 위치 조정은 Task 8).

import { importFixture, openBook, openOverlay } from './helpers';
const ratio = (f: any) => f.evaluate(() => { const e = document.scrollingElement!; return e.scrollTop / (e.scrollHeight - e.clientHeight); });

async function drag(page: any, from: { x: number; y: number }, to: { x: number; y: number }, holdMs = 0) {
  const h = page.getByTestId('scroll-handle');
  const ev = (type: string, p: { x: number; y: number }) => h.dispatchEvent(type, { clientX: p.x, clientY: p.y, pointerId: 7, pointerType: 'touch', isPrimary: true, button: 0, buttons: 1, bubbles: true });
  await ev('pointerdown', from);
  for (let i = 1; i <= 8; i++) await ev('pointermove', { x: from.x + ((to.x - from.x) * i) / 8, y: from.y + ((to.y - from.y) * i) / 8 });
  if (holdMs) await page.waitForTimeout(holdMs);
  return () => ev('pointerup', to);
}

  const release = await drag(page, start, { x: start.x - 120, y: trackTop + 32 + trackLen * 0.5 }, 3300);   // iframe 위로 벗어나며 3초 넘게 유지 (Review Focus 4)
  await expect.poll(() => ratio(f)).toBeGreaterThan(0.4);
