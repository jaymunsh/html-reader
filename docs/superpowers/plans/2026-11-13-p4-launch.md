# HTML Reader PWA — P4 바로 열기 연동 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설치된 앱에서 PC는 파일 연결(`file_handlers` + `launchQueue`), Android는 공유(`share_target`)로 들어온 ZIP/HTML을 곧바로 가져오고, 전체 기능의 최종 회귀와 수동 확인 체크리스트를 마무리한다.

**Architecture:** 두 진입로 모두 `launch` 단위가 `File[]`로 정규화해 서재의 기존 가져오기 흐름(`ImportFlow`)에 넘긴다. 공유는 SW가 POST 본문을 임시 캐시 `share-inbox`에 두고 `303 → /?import=pending`으로 보내면 앱이 꺼내 가져온 뒤 비운다.

**Tech Stack:** P1–P3과 동일(새 의존성 없음)

**Spec:** `docs/superpowers/specs/2026-11-13-html-reader-pwa-design.md` (§7.5, §11.3) — `docs/superpowers/plans/2026-11-13-index.md`의 공통 규약과 P1–P3 계획의 Interfaces를 전제로 한다.

## Global Constraints

- P1–P3의 Global Constraints 전부.
- `file_handlers`는 `.zip`, `.html`, `.htm`. `share_target`은 POST + `multipart/form-data`, `accept`에 `application/zip`, `application/x-zip-compressed`, `application/octet-stream`, `.zip`, `text/html`, `.html`을 **모두** 넣는다.
- 공유 실패 안내 문구에는 `앱에서 직접 가져오기를 이용하세요`가 들어간다.
- iOS는 이 기능을 지원하지 않는다(매니페스트 항목은 무시될 뿐, iOS 전용 분기 코드를 만들지 않는다).
- 실제 설치 앱 동작(파일 더블클릭, 공유 시트)은 자동 테스트 범위 밖이다(§11.3). 자동 테스트는 `launchQueue` 모의 객체와 폼 POST로 한다.
- `share-inbox` 캐시는 `book-*`가 아니므로 고아 정리 대상이 아니다. agent 가드(P1-21)는 이미 이 이름을 막는다.

## Review Focus

1. **지원하지 않는 파일이 섞여 들어옴**(`.pdf` 등) — 그 파일만 `ZIP 또는 HTML 파일만 가져올 수 있습니다.`로 안내하고 나머지는 계속 가져온다. (Task 1)
2. **리더가 열려 있을 때 파일이 전달됨** — 진행률을 저장하고 서재로 나간 뒤 가져온다. (Task 1)
3. **공유 직후 앱이 `?import=pending`을 처리하기 전에 닫힘/새로고침** — 다음 시작 때 `share-inbox`에 남은 파일을 가져오고, 같은 파일을 두 번 가져오지 않는다. (Task 2)
4. **파일명이 없거나 MIME이 `application/octet-stream`인 공유 파일** — 이름을 `shared-<n>`(HTML로 판별되면 `.html` 붙임)으로 정하고 내용(매직 바이트)으로 종류를 판별한다. (Task 2)
5. **여러 파일이 한 번에 전달됨** — 순서대로 하나씩 가져오고, `sourceName`이 겹치면 파일마다 교체/추가를 묻는다. (Task 1)

// launch.ts
export interface LaunchQueueLike { setConsumer(cb: (params: { files?: readonly { getFile(): Promise<File> }[] }) => void): void }
export function initLaunch(queue: LaunchQueueLike | undefined, onFiles: (files: File[]) => void): void;   // queue가 없으면 아무것도 안 함. 핸들 → File 변환, 빈 목록은 무시

```ts

launch_handler: { client_mode: ['focus-existing', 'auto'] },
```

// tests/unit/share.test.ts — Node의 Request/FormData/Response로 검증, CacheStorage는 메모리 모의
import { expect, test } from 'vitest';
import { handleShareTarget, SHARE_CACHE } from '../../src/sw/share';
import { takePendingShare } from '../../src/lib/launch';

function fakeCaches() {
  const store = new Map<string, Response>();
  const cache = {
    put: async (k: string, r: Response) => { store.set(k, r); },
    keys: async () => [...store.keys()].sort().map((k) => ({ url: 'https://app.test' + k })),
    match: async (k: any) => store.get(typeof k === 'string' ? k : new URL(k.url).pathname)?.clone(),
    delete: async (k: any) => store.delete(typeof k === 'string' ? k : new URL(k.url).pathname),
  };
  return { api: { open: async (n: string) => { expect(n).toBe(SHARE_CACHE); return cache; } } as any, store };
}
const post = (fd: FormData) => new Request('https://app.test/__app/share-target', { method: 'POST', body: fd });

test('파일을 inbox에 넣고 303 /?import=pending', async () => {
  const { api, store } = fakeCaches();
  const fd = new FormData();
  fd.append('file', new File(['PK\x03\x04zip'], '분기 보고서.zip', { type: 'application/x-zip-compressed' }));
  fd.append('file', new File(['<!doctype html><p>x'], '', { type: 'application/octet-stream' }));
  const res = await handleShareTarget(post(fd), api);
  expect([res.status, res.headers.get('Location')]).toEqual([303, '/?import=pending']);
  expect(store.size).toBe(2);
  const files = await takePendingShare(api);
  expect(files.map((f) => f.name)).toEqual(['분기 보고서.zip', 'shared-2.html']);      // Review Focus 4
  expect(await files[0].text()).toBe('PK\x03\x04zip');
  expect(store.size).toBe(0);
  expect(await takePendingShare(api)).toEqual([]);                                     // 두 번 가져오지 않는다 (Review Focus 3)
});
test('본문을 읽지 못하거나 파일이 없으면 303 /?import=failed', async () => {
  const { api, store } = fakeCaches();
  const bad = new Request('https://app.test/__app/share-target', { method: 'POST', body: 'not multipart', headers: { 'Content-Type': 'multipart/form-data; boundary=x' } });
  expect((await handleShareTarget(bad, api)).headers.get('Location')).toBe('/?import=failed');
  expect((await handleShareTarget(post(new FormData()), api)).headers.get('Location')).toBe('/?import=failed');
  expect(store.size).toBe(0);
});
