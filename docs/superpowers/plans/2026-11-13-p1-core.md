# HTML Reader PWA — P1 핵심 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ZIP/단일 HTML을 기기에 가져와 Service Worker가 `/book/<id>/…`로 서빙하고, 같은 출처 iframe에서 원본 그대로 읽으며 진행률·이어 읽기·오프라인이 동작하는 최소 PWA를 만든다.

**Architecture:** 셸(`/`, Svelte 5)이 iframe에 `/book/<id>/<path>`를 띄운다. SW가 요청 주체(book 맥락)를 판별해 Cache Storage의 파일로 응답하고 네비게이션 HTML에만 `/__reader/agent.js`를 바이트 단위로 주입한다. Import Worker가 ZIP 중앙 디렉터리를 직접 파싱해 엔트리 단위로 풀어 Cache Storage + IndexedDB에 원자적으로 커밋한다.

**Tech Stack:** Vite, TypeScript, Svelte 5, vite-plugin-pwa(injectManifest) + workbox-precaching, fflate(`Inflate`만), Vitest(+fake-indexeddb), Playwright 1.65(Chromium·WebKit·모바일 에뮬레이션)

**Spec:** `docs/superpowers/specs/2026-11-13-html-reader-pwa-design.md` — 실행자는 이 계획과 스펙, 그리고 `docs/superpowers/plans/2026-11-13-index.md`(공통 규약: 명령, 파일 구조, testid, 헬퍼)를 함께 읽는다.

## Global Constraints

- 스택 고정: Vite + TypeScript + Svelte 5 + vite-plugin-pwa(injectManifest) + fflate(`Inflate`만, 중앙 디렉터리 파서는 자체 구현) + Vitest + Playwright. 다른 런타임 의존성을 추가하지 않는다.
- 앱 정적 자산은 모두 `/__app/` 아래, agent는 `/__reader/agent.js`, 앱 HTML은 `/`만. (SW 스크립트만 `/sw.js` — 인덱스 "스펙 이슈" 1)
- 매니페스트: `display: standalone`, `start_url: /`, `scope: /`, `theme_color`·`background_color` = `#EEF0F4`.
- viewport 메타는 정확히 `width=device-width, initial-scale=1, viewport-fit=cover` — `user-scalable=no`·`maximum-scale` 금지.
- `apple-mobile-web-app-status-bar-style`은 `default`. `mobile-web-app-capable`을 두고 `apple-mobile-web-app-capable`은 보조로 병기.
- SW는 `skipWaiting`을 자동 호출하지 않는다. `clients.claim()`은 쓴다. SW는 모듈 전역 상태에 의존하지 않는다(메모는 캐시일 뿐, 진실은 IndexedDB).
- 프리캐시 정리는 `workbox-precache-*`만. `book-*` 캐시는 SW가 절대 지우지 않는다.
- IndexedDB 이름 `html-reader`, 스키마 버전 + `onupgradeneeded` 단계별 마이그레이션, `versionchange`에서 연결 닫기.
- 위치는 px가 아니라 비율(0–1)로 저장한다. 진행률은 0–100.
- HTML 주입은 네비게이션 요청 + `text/html`/`application/xhtml+xml`에만, 바이트 단위로.
- 검증은 브라우저 기반(Playwright)만. Xcode·Android 에뮬레이터 금지.
- 번들 예산: 초기 JS ≤ 50KB(gzip), agent ≤ 8KB(gzip).
- 화면 문구는 한국어. 스펙이 문구를 지정한 곳은 그대로 쓴다.
- 커밋은 태스크 끝에 한 번. 메시지는 `feat|test|chore: …` 형식.

## Review Focus

스펙이 암시하지만 스펙의 테스트 목록에는 없는 입력·실패 양식. 각 줄은 괄호 안 태스크에 테스트를 넣었다.

1. **파일명에 `#`, `?`, `%`, 공백이 든 ZIP** — 캐시 키로 저장한 경로가 요청 URL에서 온 경로와 같은 파일로 조회돼야 한다. (Task 6 `cacheKey` 왕복 테스트, Task 17 E2E)
2. **정규화 후 경로가 겹치는 엔트리**(NFC/NFD 중복, `..`·선행 `/`가 든 엔트리명, 대소문자만 다른 이름) — 가져오기가 죽지 않고 첫 엔트리를 유지하며, `..` 엔트리는 버린다. (Task 8 `sanitizeEntryPath`, Task 13 `planEntries`)
3. **가져오기 진행 중 다른 탭에서 앱이 시작됨** — 시작 시 고아 정리가 진행 중인 가져오기의 캐시를 지우면 안 된다. (Task 12 `withImportLock`/`cleanupOrphans` 건너뜀, Task 24 E2E)
4. **주입 스캔 창(4KB) 밖에 `<head>`가 있거나 0바이트·태그 없는 HTML** — 깨지지 않고 맨 앞(BOM 뒤)에 주입되고, 0바이트 HTML은 조각으로 분류된다. (Task 7, Task 10)
5. **가리키는 대상이 사라진 열기 요청**(`?open=<없는 id>`, 사라진 `lastPath`, IDB에는 있는데 캐시가 비워진 문서) — 빈 iframe이 아니라 안내 후 서재로 돌아간다. (Task 20 E2E, Task 17의 404 안내 HTML)

```ts
/// <reference lib="webworker" />
import { precache, matchPrecache } from 'workbox-precaching';
declare const self: ServiceWorkerGlobalScope & { __WB_MANIFEST: any };

precache(self.__WB_MANIFEST);
self.addEventListener('activate', (e) => e.waitUntil(self.clients.claim()));

let activeBook: string | null = null;                 // 스파이크 전용. 정식 구현은 IndexedDB(Task 16)
const navLog: { destination: string; mode: string; url: string }[] = [];
self.addEventListener('message', (e) => {
  if (e.data?.type === 'active-book') activeBook = e.data.id;
  if (e.data?.type === 'gate-log') e.ports[0].postMessage(navLog);
});

const bookOf = (pathname: string) => /^\/book\/([^/]+)\//.exec(pathname)?.[1] ?? null;

async function context(event: FetchEvent): Promise<string | null> {
  const req = event.request, url = new URL(req.url);
  if (req.mode === 'navigate') {
    if (req.destination === 'document') return null;
    return bookOf(url.pathname) ?? (req.referrer ? bookOf(new URL(req.referrer).pathname) : null) ?? activeBook;
  }
  const client = event.clientId ? await self.clients.get(event.clientId) : undefined;
  if (!client) return activeBook;
  const fromUrl = bookOf(new URL(client.url).pathname);
  if (fromUrl) return fromUrl;
  return (client as WindowClient).frameType === 'top-level' ? null : activeBook;
}

async function serve(pathname: string): Promise<Response> {
  const hit = await caches.match(pathname, { cacheName: 'book-gate-v1' });
  return hit ?? new Response('not found', { status: 404 });
}

self.addEventListener('fetch', (event) => {
  const req = event.request, url = new URL(req.url);
  if (url.origin !== self.location.origin) return;
  if (req.mode === 'navigate') navLog.push({ destination: req.destination, mode: req.mode, url: url.pathname });
  event.respondWith((async () => {
    if (url.pathname.startsWith('/__reader/')) return (await matchPrecache(url.pathname)) ?? fetch(req);
    if (req.mode === 'navigate' && req.destination === 'document') {
      const id = bookOf(url.pathname);
      if (id) {
        const path = url.pathname.slice(`/book/${id}/`.length);
        return Response.redirect(`/?${new URLSearchParams({ open: id, path })}`, 302);
      }
      return (await matchPrecache('/index.html')) ?? fetch(req);
    }
    const ctx = await context(event);
    if (ctx && !url.pathname.startsWith('/book/')) {
      if (req.mode === 'navigate') return Response.redirect(`/book/${ctx}${url.pathname}${url.search}`, 302);
      return serve(`/book/${ctx}${url.pathname}`);
    }
    if (url.pathname.startsWith('/book/')) return serve(url.pathname);
    return (await matchPrecache(url.pathname === '/' ? '/index.html' : url.pathname)) ?? fetch(req);
  })());
});
```

```ts
//  worker → main: { type: 'progress', done, total } | { type: 'need-entry', pagePaths } | { type: 'done', bookId } | { type: 'error', code, detail }
```

Worker 처리 순서(§4.3과 같은 번호):
1. 파일 종류: 이름이 `.html`/`.htm`이면 단일 HTML(경로 = 파일명 NFC, 엔트리 1개짜리 묶음으로 같은 경로를 탄다). 아니면 앞 4바이트가 `PK\x03\x04` 또는 `PK\x05\x06`인지 보고 ZIP으로 처리, 둘 다 아니면 `unsupported-file`.
2. `readCentralDirectory` → `planEntries` → `precheck(files, await navigator.storage?.estimate?.() ?? null)`.
3. `withImportLock` 안에서: `newBookId()`, `cacheNameFor(id, 1)` 캐시를 열고 파일마다 `readEntry` → `cache.put(cacheKey(id, path), new Response(blob, { headers: { 'Content-Type': type, 'Content-Length': String(blob.size) } }))`를 **await**한 뒤 다음 파일로. 진행률은 `onBytes` 누적.
4. HTML 파일(`isHtmlPath`)은 Blob을 바이트로 읽어 `isFullDocument`면 `pagePaths`에 넣고, `decodeHtml`→`extractTitle`을 `titles[path]`에, `extractText`를 `texts`에 넣는다. Content-Type은 `mimeFor(path)`이되 `detectEncoding().source`가 `utf8`/`fallback`이면 `; charset=<encoding>`을 붙인다(스펙 이슈 7).
5. `pagePaths`를 `naturalComparePaths`로 정렬. `pagePaths`가 비면 `no-html`. `pickEntryPath`가 null이면 `need-entry`를 보내고 `entry` 응답을 기다린다(null이면 `cancelled`).
6. 제목: `dedupeTitle(defaultTitle(titles[entryPath] ?? '', sourceName), 기존 제목들)`.
7. `commitNewBook`(트랜잭션 1개). 성공하면 `done`.
8. 어떤 단계에서든 실패하면 `caches.delete(cacheName)` 후 `error`. `ZipError.code`는 그대로, `QuotaExceededError`는 `quota`, 그 외는 `failed`.

`client.ts`: Worker는 `new Worker(new URL('./importer.worker.ts', import.meta.url), { type: 'module' })`로 가져오기마다 새로 만들고 끝나면 `terminate()`.

```ts
export const PROTOCOL_VERSION = 1;
export const APP_TAG = 'html-reader';
export type Mods = { ctrl: boolean; meta: boolean; alt: boolean; shift: boolean };
export type AgentMsg =
  | { type: 'ready'; path: string; title: string }
  | { type: 'scroll'; pct: number; ratio: number }      // pct: 0–100 = (scrollTop+clientHeight)/scrollHeight, ratio: 0–1 = scrollTop/(scrollHeight-clientHeight)
  | { type: 'tap' }                                     // P2
  | { type: 'key'; key: string; mods: Mods }            // P2
  | { type: 'open-external'; url: string };
export type Restore = { scrollRatio: number } | { find: { query: string; snippet: string } } | { bookmark: { scrollRatio: number } };
export type ShellMsg =
  | { type: 'init'; textScale: number; restore?: Restore }
  | { type: 'scroll-to'; ratio: number }                // P2
  | { type: 'set-scale'; textScale: number }            // P2
  | { type: 'find'; query: string; snippet: string };   // P3
export type Envelope<T> = T & { app: typeof APP_TAG; protocolVersion: number };
export function wrap<T extends AgentMsg | ShellMsg>(msg: T): Envelope<T>;
export type Parsed<T> = { ok: true; msg: T } | { ok: false; reason: 'foreign' | 'version' | 'invalid' };
export function parseAgentMessage(data: unknown): Parsed<AgentMsg>;
export function parseShellMessage(data: unknown): Parsed<ShellMsg>;
```
